# Лабораторные работы по параллельному программированию

**Автор:** Сахнова Кристина

В этом репозитории собраны лабораторные работы по курсу параллельного программирования. В каждой папке находится исходный код, скрипты для запуска, графики и подробный отчет.

## Список работ

| № | Тема | Технология | Ссылка на отчет |
|---|---|---|---|
| 1 | Умножение квадратных матриц | Последовательное (C++) | [Открыть](lab1/README.md) |
| 2 | Параллельное умножение матриц | OpenMP | [Открыть](lab2/README.md) |
| 3 | Распределенное умножение матриц | MPI | [Открыть](lab3/README.md) |
| 4 | Умножение матриц на GPU | CUDA | [Открыть](lab4/README.md) |

## Структура репозитория

- `lab1/` — последовательная реализация, эксперименты с размерами.
- `lab2/` — реализация на OpenMP, эксперименты с потоками и размерами матриц.
- `lab3/` — реализация на MPI (суперкомпьютер «Сергей Королёв»).
- `lab4/` — реализация на CUDA (видеокарта NVIDIA Tesla T4), эксперименты с сетками блоков.
